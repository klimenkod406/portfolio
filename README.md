# Портфолио — Денис Клименко

Одностраничный сайт-портфолио. Всё лежит в одном `index.html` плюс папка `assets/` —
ни сборки, ни зависимостей, ни сервера. Достаточно открыть `index.html` двойным кликом.

## Что внутри

- **Баннер** — кольцо из превью проектов на чистом `requestAnimationFrame`: ближняя дуга
  крупная и резкая, дальняя мелкая и размытая. Фраза в заголовке печатается посимвольно.
- **Работы** — 10 проектов, у каждого полноэкранный просмотр: живое демо сайта,
  архитектурная схема, техдокументация, галерея кадров.
- **Стек, обо мне, контакты** — факты и ссылки.
- **Терминал** — по клавише `~`.
- **Пять языков** — русский, английский, украинский, немецкий, испанский. Язык
  определяется по выбору посетителя, затем по языку браузера, затем по часовому поясу;
  ручной выбор сохраняется в `localStorage`. Поддерживается `?lang=en` в адресе.
